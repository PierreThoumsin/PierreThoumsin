# 📚 docs

## 🎯 Rôle

Documents de référence du projet : les règles et la méthode qui s'appliquent à tout le dépôt.

## 📂 Contenu

| Fichier | Contenu | Statut |
|---|---|---|
| `conventions.md` | toutes les règles du projet : langue, nommage, en-tête YAML, README, branches, Pull Requests, commits, données sensibles | ✅ valide |

## 📏 Règles

- Chaque document de ce dossier (hors `README.md`) DOIT porter l'en-tête YAML à 3 champs (`titre`, `statut`, `mis-a-jour`).
- Un document n'entre ici qu'après validation de son principe par le dirigeant.
- `conventions.md` est la source unique des règles : elles ne sont recopiées nulle part ailleurs.
